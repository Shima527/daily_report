## わかったこと
#### git clone
- リポジトリを複製すること
#### リモートリポジトリ
- cloneしてきた元のリポジトリ
- Githubにあるリポジトリがリモートリポジトリであることがほとんどだけど、ローカルリポジトリからローカルリポジトリへcloneして複製することができるため、ローカルリポジトリにあるが、リモートリポジトリとなることもある。
#### リモート(追跡)ブランチ
- クローン元のブランチ。
- Fetchした場合、このブランチに更新履歴が反映される。
#### Reference
- ローカルブランチ main の正式名称は、refs/heads/main
- リモートブランチ origin/mainの正式名称は、refs/remotes/origin/main
#### プルの動き
- Fetch + Merge
- リモートブランチの更新履歴が反映されて、リモートブランチとローカルブランチをマージする。
