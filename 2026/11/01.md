## わかったこと
#### リベース
- git rebase -i を使うことで、コミットの履歴を修正することができる。
- git rebase -i HEAD~任意の数字で、コミット履歴を遡って、どのコミットを修正するかを指定できる。
- git rebase -i をすると、pick コミットIDが表示され、そこから修正するコミットを選択する。
- 表示されたコミットを削除すれば、そのコミットは削除され、順番を並び替えれば、コミットの順番は入れ替わる。
- pick → edit: コミットメッセージを修正、git reset HEAD^で修正を変更することも可能。
- pick → squshで指定したコミットとその直前のコミットをまとめることができる。
- リモートとローカルの差異がある状態(両方でコミットが一つ積まれているなど)でpullを実行すると、警告が出て、pullが実行できない場合がある。その場合、pullの設定をすることで解消する(rebase or merge or first forward only )
