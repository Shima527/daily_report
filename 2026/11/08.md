## わかったこと
#### Github flow
1. mainブランチをローカルリポジトリに作成し、リモートリポジトリへpush。
2. mainブランチから開発ブランチを切って、その開発ブランチで開発をする。
3. リモートリポジトリへ開発リポジトリをpushし、pull requestを作成する。
4. pull requestが承認されたら、mainブランチに開発ブランチをマージする。承認されない場合、修正し再度pushする。
5. ローカルリポジトリのmainブランチでリモートリポジトリからmainをpullして、mainブランチを最新化する。(git pull origin main --rebase)
