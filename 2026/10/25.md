## わかったこと
### gitの裏側
- 圧縮ファイル、ツリーファイル、コミットファイルを作成することで、変更管理を実現している。
- 
**新規ファイル作成時**
- git add・・・リポジトリに圧縮した対象ファイルをリポジトリに保存。ステージに対象ファイル名と圧縮した対象ファイルをマッピング。（マッピングはindexファイルに記載）
- git commit・・・indexファイルを元に、ツリーファイルを作成。（内容はindexファイルと同じ）ツリーファイルからコミットファイルを作成。（ファイルの作成者、日時、コミットメッセージを記載）<br>

**既存ファイル修正**
- git add ・・・ 圧縮するのは新規作成時と同じで、indexファイルの対象圧縮ファイルを置き換える。
- git commit・・・新規作成時と違い、コミットファイル作成時に親コミットを記載する。親コミットと現コミットを比較することで、差分を出力することができるし、前の状態に戻すことができる。
