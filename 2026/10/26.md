## わかったこと
- git diff は ワークツリーとステージの比較して、差分を出力する。
- git diff --staged はステージのとリポジトリのコミットを比較して、差分を出力する。
- コミットした直後は、当然どこにも変更がないので、git diffコマンドを実行しても、何も出力されない。どのエリアのファイルが比較されているのかを意識する。
