## わかったこと
- 仮想化というが、Dockerは完全な仮想化というより、ホストOS上のプロセスの一つ。
- Docker（Docker Engine・・・Dockerのソフトウェア）はLinux上でしか動かすことができない。
（LinuxカーネルのNamespace機能で他プロセスと隔離しているから）
- Docker DesktopにはLinuxも含まれているため、MacOSやWindows OS上で動かすことができる。
- Dockerのコマンドは、そのコマンドが「なにを」「どうするのか」で考えると理解が深まる。ex. docker run ・・・イメージをコンテナにして、起動する。
- docker compose はあくまでもコンテナの起動を楽に行うためのツール。
